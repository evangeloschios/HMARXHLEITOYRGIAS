Έξι ασκήσεις στις Γεννήτριες Σ.Ρ.

Παρόμοιες με τα παραδείγματα της σελίδας 105 — πρώτα λύση από τον μαθητή, μετά εμφάνιση απάντησης με κουμπί.

Κεφ. 2.3.5 Διακύμανση τάσης Βαθμός απόδοσης Απώλειες Ακέραια αποτελέσματα
Οδηγία: Κάθε μαθητής λύνει πρώτα την άσκηση στο τετράδιό του. Μετά πατά το κουμπί «Εμφάνιση λύσης» κάτω από την αντίστοιχη άσκηση.
Διακύμανση τάσης:
ε% = [(U₀ − UΝ) / UΝ] · 100
Βαθμός απόδοσης:
η = P / Pεισ
Συνολικές απώλειες:
Pαπ = Pεισ − P ή Pαπ = Pσταθ + Pμεταβλ

1 Υπολογισμός τάσης πλήρους φορτίου

Σε μια γεννήτρια Σ.Ρ. η διακύμανση της τάσης είναι ε = 5%. Αν η τάση εν κενώ είναι U₀ = 231V, να βρεθεί η τάση της γεννήτριας υπό πλήρες φορτίο UΝ.
ε = 5%U₀ = 231VΖητείται: UΝ

Λύση

  1. Χρησιμοποιούμε τη σχέση: ε% = [(U₀ − UΝ) / UΝ] · 100
  2. 5 = [(231 − UΝ) / UΝ] · 100
  3. 5UΝ = 23100 − 100UΝ
  4. 105UΝ = 23100
  5. UΝ = 23100 / 105 = 220V
Απάντηση: UΝ = 220V

2 Υπολογισμός τάσης εν κενώ

Σε μια γεννήτρια Σ.Ρ. η τάση υπό πλήρες φορτίο είναι UΝ = 200V και η διακύμανση τάσης είναι ε = 10%. Να βρεθεί η τάση εν κενώ U₀.
UΝ = 200Vε = 10%Ζητείται: U₀

Λύση

  1. Από τη σχέση: ε% = [(U₀ − UΝ) / UΝ] · 100
  2. 10 = [(U₀ − 200) / 200] · 100
  3. 10 · 200 = 100(U₀ − 200)
  4. 2000 = 100U₀ − 20000
  5. 100U₀ = 22000, άρα U₀ = 220V
Απάντηση: U₀ = 220V

3 Υπολογισμός διακύμανσης τάσης

Σε μια γεννήτρια Σ.Ρ. η τάση εν κενώ είναι U₀ = 250V και η τάση υπό πλήρες φορτίο είναι UΝ = 200V. Να βρεθεί η διακύμανση τάσης ε%.
U₀ = 250VUΝ = 200VΖητείται: ε%

Λύση

  1. Χρησιμοποιούμε: ε% = [(U₀ − UΝ) / UΝ] · 100
  2. ε% = [(250 − 200) / 200] · 100
  3. ε% = (50 / 200) · 100
  4. ε% = 25%
Απάντηση: ε = 25%

4 Βαθμός απόδοσης και συνολικές απώλειες

Γεννήτρια Σ.Ρ. αποδίδει ηλεκτρική ισχύ P = 15kW. Η κινητική ισχύς που δέχεται στον άξονά της είναι Pεισ = 20kW. Να βρεθούν: α) ο βαθμός απόδοσης και β) οι συνολικές απώλειες.
P = 15kWPεισ = 20kWΖητούνται: η, Pαπ

Λύση

  1. Ο βαθμός απόδοσης είναι: η = P / Pεισ
  2. η = 15 / 20 = 0,75, δηλαδή η = 75%
  3. Οι συνολικές απώλειες είναι: Pαπ = Pεισ − P
  4. Pαπ = 20 − 15 = 5kW
Απάντηση: η = 75% και Pαπ = 5kW

5 Βαθμός απόδοσης με σταθερές και μεταβλητές απώλειες

Γεννήτρια Σ.Ρ. αποδίδει ισχύ 25HP. Δίνονται 1HP = 0,736kW. Οι σταθερές απώλειες είναι 900W και οι μεταβλητές απώλειες 700W. Να βρεθεί ο βαθμός απόδοσης της γεννήτριας.
P = 25HP1HP = 0,736kWPσταθ = 900WPμεταβλ = 700W

Λύση

  1. Μετατρέπουμε την αποδιδόμενη ισχύ σε W: P = 25 · 0,736kW = 18,4kW = 18400W
  2. Υπολογίζουμε τις συνολικές απώλειες: Pαπ = 900 + 700 = 1600W
  3. Η ισχύς εισόδου είναι: Pεισ = P + Pαπ = 18400 + 1600 = 20000W
  4. Ο βαθμός απόδοσης είναι: η = P / Pεισ = 18400 / 20000 = 0,92
  5. Άρα: η = 92%
Απάντηση: η = 92%

6 Εύρεση ισχύος εισόδου και απωλειών

Γεννήτρια Σ.Ρ. αποδίδει ηλεκτρική ισχύ P = 16kW και έχει βαθμό απόδοσης η = 80%. Να βρεθούν: α) η απαιτούμενη κινητική ισχύς εισόδου και β) οι συνολικές απώλειες.
P = 16kWη = 80%Ζητούνται: Pεισ, Pαπ

Λύση

  1. Γράφουμε τον βαθμό απόδοσης ως δεκαδικό αριθμό: η = 80% = 0,80
  2. Από τη σχέση η = P / Pεισ βρίσκουμε: Pεισ = P / η
  3. Pεισ = 16 / 0,80 = 20kW
  4. Οι απώλειες είναι: Pαπ = Pεισ − P = 20 − 16 = 4kW
Απάντηση: Pεισ = 20kW και Pαπ = 4kW
Οι τιμές έχουν επιλεγεί ώστε τα τελικά αποτελέσματα να είναι ακέραιοι αριθμοί. Στην εκτύπωση οι λύσεις εμφανίζονται όλες για χρήση από τον εκπαιδευτικό.
